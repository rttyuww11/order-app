# COZY 프런트엔드

React와 바닐라 JavaScript로 구성된 Vite 커피 주문 애플리케이션입니다. 현재 메뉴는 화면 확인을 위한 샘플 데이터입니다.

## 시작하기

```sh
npm install
npm run dev
```

개발 서버 주소는 터미널에 표시됩니다.

## 명령어

```sh
npm run build    # 프로덕션 빌드
npm run preview  # 프로덕션 빌드 미리보기
npm run lint     # Oxlint 검사
```

## 주문 접수

주문하기 버튼은 장바구니의 실제 메뉴·수량·옵션·금액을 브라우저 저장소에 주문 접수 상태로 저장하고, 해당 수량만큼 재고를 차감합니다. 주문 후 고객은 주문하기 화면에 남으며, 접수 내용은 관리자 화면에서 확인할 수 있습니다. 실제 서비스에서 여러 사용자·기기 간 주문과 재고를 공유하려면 이 동작을 서버의 주문 API 및 원자적 재고 처리로 대체해야 합니다.

## 재고 한도

관리자 화면의 재고와 주문 화면은 같은 브라우저 저장 데이터를 사용합니다. 메뉴 카드의 `담기`와 장바구니 수량 증가는 해당 메뉴의 설정 재고를 넘지 않으며, 옵션이 다른 동일 메뉴도 재고 한도를 함께 사용합니다. 주문 전에도 최신 재고를 다시 확인합니다.

현재 재고 한도는 프런트엔드에서 적용됩니다. 여러 사용자나 기기에서 동시에 주문을 받는 환경에서는 주문 API에서도 재고 확인과 차감을 원자적으로 처리해야 합니다.

## 디렉터리

- `src/`: React 애플리케이션 코드
- `public/`: 빌드 시 그대로 복사되는 정적 파일
- `dist/`: 프로덕션 빌드 출력물
