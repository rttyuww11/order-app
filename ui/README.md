# COZY 프런트엔드

React와 바닐라 JavaScript로 구성된 Vite 애플리케이션입니다.

## 시작하기

```sh
npm install
npm run dev
```

개발 서버 주소는 터미널에 표시됩니다.

## 명령어

```sh
npm run build    # 프로덕션 빌드
npm run preview  # 프로덕션 빌드 미리보기
npm run lint     # Oxlint 검사
```

## 디렉터리

- `src/`: React 애플리케이션 코드
- `public/`: 빌드 시 그대로 복사되는 정적 파일
- `dist/`: 프로덕션 빌드 출력물
